## Phase Goal

**As a** 装修中的家庭成员，**I want to** 在手机上快速记下第一笔装修支出并随时回看，**so that** 全家的装修开销都有记录。

<objective>
端到端打通"打开应用 → 记一笔 → 回首页看到记录"的最小完整路径，并建立项目骨架、视觉令牌与部署配置（Walking Skeleton）。

Purpose: 用最薄的纵向切片证明架构（Vite + Vue3 + Vant4 + Pinia + Dexie + PWA → EdgeOne Pages）全链路可行，后续阶段在此骨架上叠加能力。
Output: 可本地运行并部署到 EdgeOne Pages 的记账应用骨架；SKELETON.md 已生成，作为架构契约。
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| 用户输入 → 本地存储/渲染 | 金额、备注等未受信输入进入 IndexedDB 并回显 |
| 依赖安装 → 项目代码 | npm 依赖引入供应链风险 |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-01 | Tampering | 备注/金额渲染 | medium | mitigate | Vue 文本插值渲染，禁止 v-html；金额仅数字校验 |
| T-01-02 | Denial of Service | Dexie 本地库 | low | accept | 家庭级单机数据量小；保留 schema version 以便升级 |
| T-01-03 | Tampering | npm 依赖 | high | mitigate | npm audit + package-legitimacy 检查；依赖锁定 package-lock.json |
</threat_model>
