  <name>Task 1: 端到端——创建账本并同步一笔记录（D-01, D-03）</name>
  <files>functions/api/ledger.ts, src/api/client.ts, src/db/sync.ts, src/pages/HomeView.vue, edgeone.json</files>
  <action>
    建立 EdgeOne Pages Functions API（functions/ 目录，Node Functions）：
    - POST /api/ledger：创建账本，生成 ledgerId 与 6 位邀请短码，向 Blob 写入初始账本文件（key: ledgers/{ledgerId}.json，含 version、members[]、records[]、inviteCode）
    - GET /api/ledger?ledgerId=：读取账本文件（strong 一致性）
    - PUT /api/ledger：整文件更新（读-改-写 + version 乐观锁：请求携带 baseVersion，服务端不匹配返回 409）
    - Blob 使用 @edgeone/pages-blob 的 getStore，binding 名称通过环境变量/配置注入
    建立 src/api/client.ts：封装上述 REST 调用（fetch，错误处理）。
    建立 src/db/sync.ts：pushLedger(localData)（本地→云端 PUT）与 pullLedger(ledgerId)（云端→本地合并，按 updatedAt last-write-wins、tombstone 保留，D-03）。
    HomeView 增加"创建账本"入口：无账本时显示创建按钮；创建后进入账本首页（本地 ledgerId 存 localStorage）。
    仅打通单路径：创建 → 本地记一笔 → 手动 push → pull 回本地显示；不实现自动轮询（Plan 03）。
  </action>
