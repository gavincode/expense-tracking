# Phase 3 User Setup: EdgeOne Blob 存储

> 后端"文件数据库"需要你在 EdgeOne 控制台创建 Blob 存储并绑定到 Pages Functions。

> **重要（中国大陆访问）**：EdgeOne 项目自带的默认域名在大陆网络下**只能**通过控制台的"预览链接"访问，链接 3 小时过期，过期后返回 401——不能直接发给家人使用。要让国内手机稳定访问，**必须绑定自定义域名**（加速区域选「全球可用区（不含中国大陆）」时**无需 ICP 备案**）。

## 目标

创建 Blob 存储（账本文件持久化）、绑定自定义域名，并让 `functions/api/*` 能访问它。

## 操作步骤

1. 打开 [EdgeOne Pages 控制台](https://edgeone.cloud.tencent.com/pages)（或 EdgeOne Makers 控制台）
2. 创建/进入项目时，**加速区域选择「全球可用区（不含中国大陆）」**（重要：选含大陆区域时未备案域名无法稳定访问）
3. **添加自定义域名**（大陆访问的关键步骤）：
   - 准备一个自己的域名（需先在域名注册商购买，如 `.com`/`.cn`/`.top` 等，最便宜的一年几十元即可）
   - 项目 → **域名管理 / Domain** → **添加自定义域名**，输入根域名或子域名（如 `zhangben.example.com`）
   - 按控制台提示，在域名注册商处添加 DNS 解析记录（验证归属权 + 添加 CNAME）
   - 平台会自动为自定义域名配置免费 HTTPS 证书，等待生效即可
4. 进入项目 → **存储 / Storage** → **Blob**
5. 创建一个 Blob 存储，名称建议 `ledgers`（与代码默认读取的 `BLOB_STORE_NAME` 一致）
6. 在项目环境变量/绑定中设置 `BLOB_STORE_NAME=ledgers`（若存储名不同则改成实际名称）
7. 部署 `functions/` 目录下的 API（随仓库一起部署即自动生效）

> **大陆访问说明**：
> - 加速区域为「全球可用区（不含中国大陆）」时，绑定自定义域名**无需备案**，国内手机可直接访问（走国际线路，速度比大陆节点稍慢，但记账类应用完全够用）。
> - 若日后需要国内高速访问，可先为域名完成 ICP 备案，再将加速区域切换为含大陆区域。
> - 项目自带域名在国内只能使用 3 小时有效的预览链接，不适合正式使用。

## 验证

- 部署后浏览器打开 `https://<你的域名>/api/ledger`，GET 应返回 `{"error":"ledgerId required"}`（400）——说明函数已上线
- 应用内"创建账本"成功且同步按钮可用，说明 Blob 读写正常
- 用国内手机（断开 Wi-Fi 用 4G/5G）访问 `https://<你的域名>`，确认页面可打开且能记一笔
