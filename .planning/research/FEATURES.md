# Feature Landscape

**Domain:** 装修开销记账（家庭共享）
**Researched:** 2026-08-13

## Table Stakes

功能：用户对任何记账应用的基本预期，缺失会显得"不完整"。

| Feature | Why Expected | Complexity | Notes |
|---------|--------------|------------|-------|
| 快速记一笔（金额+分类，几秒完成） | 记账工具的第一价值 | Low | 打开即记、常用项一键选是本项目明确要求 |
| 支出列表与详情（时间、金额、分类、备注） | 基本记录能力 | Low | 支持编辑/删除 |
| 分类体系 | 记账的基本组织方式 | Low | 装修场景下用阶段/空间组织 |
| 汇总统计（总支出、按分类小计） | 用户想"知道花了多少" | Medium | 装修全过程总览 |
| 预算对比（预算 vs 实际） | 装修记账的核心价值 | Medium | 每个阶段/空间单独预算、剩余与超支提醒（已确认） |
| 编辑/删除/纠错 | 基本可信赖感 | Low | 需要记录操作人，避免家庭误会 |

## Differentiators

让这个小应用"好用又好看"的加分项。

| Feature | Value Proposition | Complexity | Notes |
|---------|-------------------|------------|-------|
| 装修预算模板（常见装修支出预设：硬装/软装/家电、瓷砖/油漆/人工费） | 用户不用从零建分类 | Low | 对标"装修预算表""初创装修记账"等成熟产品 |
| 按阶段/空间组织（硬装、软装、家电 / 客厅、厨房） | 贴合装修过程，天然可汇报 | Low | 本项目核心形态 |
| 邀请链接/二维码加入共享账本 | 家人零门槛协作 | Medium | 已确认；邀请带有效期与一次性限制 |
| 记录归属（谁记的/谁改的） | 家庭协作信任感 | Medium | 轻量审计，不做复杂权限 |
| 美观的移动端设计（柔和配色、圆角卡片、清晰大字号） | 女性家人愿意用 | Medium | "简洁时尚漂亮"是明确要求 |
| 拍照留凭证（小票/合同照片） | 翻旧账有据可查 | Medium | v2 候选 |
| 生成分享卡片（"这个月装修花了 X"） | 家庭沟通的传播点 | Medium | v2 候选 |
| 语音记账 | 更快更自然 | High | v2 候选，需语音识别接入 |
| CSV 导出 | 数据不锁定 | Low | v2 候选 |

## Anti-Features

明确不做。

| Anti-Feature | Why Avoid | What to Do Instead |
|--------------|-----------|-------------------|
| 贷款/分期/税费计算 | 超出家庭记账范围，复杂度高 | 只记录实际支出 |
| 报销、发票管理 | 非家庭场景 | 用备注+照片凭证代替 |
| 复杂角色权限（管理员/成员分级） | 家庭规模不需要 | 单一共享账本+记录归属 |
| 社交/社区/广告 | 破坏简洁与隐私 | 保持纯粹工具 |
| 微信小程序 | 用户选定 H5 + EdgeOne 部署 | 先做 PWA，必要时再评估 |
| 原生 App | 与 EdgeOne 部署方向不符 | PWA 可添加到主屏幕 |

## Feature Dependencies

```
账号/登录 → 账本（创建/加入） → 分类体系 → 记一笔 → 统计汇总
                                    ↘ 预算设置 → 预算对比/超支提醒
账本 → 邀请链接 → 家人加入 → 多设备同步
```

## MVP Recommendation

优先：
1. 手机号（或账号）登录 + 创建账本
2. 装修分类预设（阶段/空间）与快速记账（3 秒一笔）
3. 每个分类的预算设置、剩余金额与超支提醒
4. 邀请链接/二维码共享账本 + 多设备同步
5. 简洁美观的支出汇总页

推迟：照片凭证、语音记账、分享卡片、CSV 导出（v2）。
